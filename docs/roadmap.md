# Roadmap

The ordered backlog of work items and the single place that tracks status. Claude updates it in each work item's PR. On `main`, an item shows `Done` once its PR has merged. In-progress stages are visible on the work branch and in the PR. No separate ticket system is used.

**Status values:** `Idea` → `Intent` → `Spec` → `Plan` → `Build` → `Preview` → `Done`
